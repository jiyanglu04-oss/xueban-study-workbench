# 学伴 · 大学生学习工作台

因为忘交一次作业，我做了一个通知整合工作台。

把课表、待办、学习平台通知、在线学习任务与考试安排放在一起。面向 Windows 电脑，本地优先，日常使用不依赖大模型。

![学伴电脑端总览，演示数据](docs/screenshots/overview.jpg)

> 图中课程、任务和通知是演示数据。它是个人学习辅助项目，不是教学平台官方产品，不保证所有学校、平台账号或界面版本都适配，也不提供代刷、代交或自动完成考试。

## 第一次使用：从这里开始

**普通用户不需要安装 Git，也不需要自己写代码。**

1. 打开 [最新版本下载](https://github.com/jiyanglu04-oss/xueban-study-workbench/releases/latest)，选择 Assets 中的 **xueban-v1.3.1-windows.zip**。
2. 完整解压到准备长期保留的普通文件夹，例如 D 盘的 xueban。不要在压缩包内直接运行。
3. 双击 **启动工作台.bat**。首次需要联网下载本项目使用的 Python 与组件，耗时取决于网络。
4. 浏览器打开 http://127.0.0.1:8765/ 后，按向导设置学期、上传并校对课表、登录自己需要的平台、进行第一次同步。
5. 想方便日常进入，可双击 **创建桌面快捷方式.bat**。

只收藏本地网址不会在开机后自动启动服务。通过 BAT 启动时请保留服务窗口，可最小化；关闭它后，本地服务可能停止。

也可通过 GitHub 的 Code → Download ZIP 下载源码；当前源码同样提供启动入口。Releases 中的 ZIP 是为直接使用准备的固定版本。

[详细 PDF 图文教程](docs/guide/学伴-v1.3-新手图文使用教程.pdf) · [文字教程](docs/guide/详细使用教程.md) · [12 张操作指引图](docs/guide/指引图)

教程截图基于 v1.3，界面位置基本一致。教程第 13 节提到的便携 Python 环境路径问题，已在本仓库 v1.3.1 修复；不代表已经在每台新电脑验证了系统任务注册，请开启后检查实际状态。

## 把这个链接交给 AI，怎么说？

可以复制这段话，连同仓库链接一起发给具备代码/文件操作能力的 AI 助手：

> 请帮助我在自己的 Windows 电脑上使用学伴工作台。
> 仓库：https://github.com/jiyanglu04-oss/xueban-study-workbench
> 先阅读 README.md、AGENTS.md 和 docs/AI使用指南.md，确认环境与使用限制。
> 我只需要安装和使用，不要擅自改代码或清空已有数据。
> 请帮助我获取最新发布包、完整解压、准备运行环境和启动本机工作台。
> 课表识别后让我校对；学习平台登录、验证码和通知授权由我自己完成。
> 不要上传我的数据库、课表、群通知、Cookie、日志或密钥。任何云端配置或公网部署请先问我。

**这个链接是项目入口，不是在线运行地址。** 别人需要在自己的电脑上下载并运行；AI 可以帮助理解、安装、排障和开发，但普通聊天模型不能仅凭链接就直接操作电脑，也不会自动获得用户的学习平台登录权限。

日常同步由项目脚本完成，课表图片由 Windows 本机 OCR 处理，不需要 AI 账号或大模型 API 密钥。

## 主要功能

| 页面 | 可以做什么 |
| --- | --- |
| 总览 | 看今日课程、临近截止的任务、未读消息和备考倒计时 |
| 我的课表 | 上传课表图片并校对，调整起止周、单双周、星期、节次与教室 |
| 待办事项 | 添加/编辑任务、设置截止时间和优先级、记录完成状态 |
| 消息中心 | 按平台筛选、搜索通知、标记已读、转为待办 |
| 在线学习 | MOOC 学习任务进入待办，相关进度显示在消息中心，不混入线下课表 |
| 备考与考试 | 四六级计划和打卡，多门期末考试日期与独立倒计时 |
| 平台入口 | 访问平台、查看连接状态、手动补录群通知 |
| 设置 | 学期作息、同步、提醒与数据备份 |

课表图片要求清晰，并保留星期列和节次栏。识别需要 Windows 中文 OCR 语言功能；识别结果可能错误，必须校对。没有识别条件时可以手动录入。

起始周、结束周和单双周都按教学周计算。开学日期会换算为所在周的周一；作息模板请按自己的学校核对。

## 同步范围与限制

当前适配超星学习通、雨课堂、中国大学 MOOC 的相关信息。同步需要联网和自己的有效登录状态，平台改版或账号差异可能导致失败。

教务系统不在默认自动抓取范围内；微信群、QQ 群和邮箱不自动读取，请到“平台入口 → 手动补录消息”补充。

通知中的任务和截止时间按规则辅助提取。手动“转待办”或“新建待办”可能预填默认时间，必须核对原通知；不确定时清空截止时间。标记已读、勾选完成都不会代替原平台提交或学习。

## 日常同步与提醒

- 手动更新：页面中的“设置 → 立即同步”，或“一键同步数据.bat”。
- 补登录：设置中的“同步方法 → 重看设置向导”，或“重新登录.bat”。
- 自动同步：在设置里按需开启，填写时间，检查回读状态确实为已开启。
- 页面桌面提醒：需要工作台页面打开，并由用户自行完成通知授权。
- 独立每日提醒：注册成功后由另一条 Windows 任务执行，和自动同步是两回事。

电脑关机时不会继续抓取或在本机弹出提醒。任务注册可能被权限/系统环境限制；如果显示“开机自启（备用方案）”，只表示登录电脑后跑一次，不等于按多个时段定时执行。

首次设置不自动开启上述所有功能。

## 数据、隐私与备份

默认完整模式的工作台数据位于 data/workbench.sqlite3，服务仅监听 127.0.0.1。平台登录状态位于 sync/state/，属于敏感信息；不保存用户输入的校园密码不等于没有登录凭证。

定期到设置里“导出备份”。导入备份会覆盖当前工作台数据，先备份再操作；换电脑通常还需要重新登录学习平台。

可选的 weapp 微信小程序功能需要额外配置云开发，并把选定的任务/通知等数据同步到云端，不属于默认本地使用流程。默认本地存储不等于任何模式都不联网。

请勿公开数据库、浏览器登录状态、个人备份、sync/debug/、sync/logs/ 或 sync/push_config.json。调试记录可能包含私人信息，不要直接发到公开 Issue。卸载或移动目录前，先备份并取消已注册的定时任务。

## 想修改代码，或让 AI 帮你开发？

阅读 [AI 使用与开发指南](docs/AI使用指南.md) 和 [AGENTS.md](AGENTS.md)。

项目由 HTML/CSS/JavaScript 前端、Python 本机 API、SQLite 数据库和平台同步适配器组成。运行环境由启动脚本准备；开发时也可使用自己的 Python 3.11+ 虚拟环境。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r sync\requirements.txt
.\.venv\Scripts\python.exe build.py
.\.venv\Scripts\python.exe -m backend.server --no-open
```

然后在本机浏览器访问 http://127.0.0.1:8765/。OCR 需要相应 Windows 系统功能；不应把开发服务器暴露到公网。

测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -t .
node tests/test_frontend_state.cjs
python tools/audit_publication.py
```

平台抓取会改写单文件 HTML 的同步数据块。准备提交或发布时，必须在干净副本中重新构建并审计；不要提交包含个人快照的 HTML。

## 项目结构

```text
backend/       本机 API、SQLite、课表图片识别
src/           界面源代码
sync/          平台适配、同步、登录检测、提醒
tests/         后端、解析与前端状态测试
assets/        图标资源
weapp/         可选微信小程序与云函数
docs/          AI 指南、图文教程、演示截图
tools/         公开发布前的检查工具
build.py       生成干净的单文件页面
学伴.html      单文件离线入口
启动工作台.bat  完整模式启动入口
```
