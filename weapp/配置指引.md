# 小程序配置指引

> 全部只需要做一次，大约 20 分钟（不含注册审核时间）。
> 代码已经写好了，你要动手的地方一共 4 个：一个小程序文件、一个电脑文件、两个云函数环境变量。

---

## 你要拿到的 5 个值

| 值 | 从哪来 | 填到哪 |
| --- | --- | --- |
| **AppID** | mp.weixin.qq.com → 设置 → 基本设置 | 开发者工具「详情 → 基本信息」 |
| **云开发环境 ID** | 开发者工具「云开发」控制台左上角 | `weapp/miniprogram/config.js` 的 `ENV_ID` |
| **订阅消息模板 ID** | mp.weixin.qq.com → 功能 → 订阅消息 | `config.js` 的 `TEMPLATE_IDS` + 云函数 `remind` 的 `TEMPLATE_ID` |
| **自己编的密钥** | 随便敲一串 32 位随机字符 | 云函数 `ingest` 的 `INGEST_KEY` + 电脑端 `ingestKey` |
| **HTTP 访问地址** | 云开发控制台 → HTTP 访问服务 | 电脑端 `sync/push_config.json` 的 `baseUrl` |

> **绑定码**（第 8 步用）不用提前准备 —— 小程序打开后自动生成，从手机上抄到电脑上就行。

---

## 第 1 步：注册一个小程序账号

1. 打开 <https://mp.weixin.qq.com/> → 右上角「立即注册」→ 选 **小程序**
2. 用一个**没注册过公众号/小程序**的邮箱，收邮件点激活链接
3. 主体类型选 **个人**，用你的微信扫码 + 身份证信息验证
4. 登录后在「设置 → 基本设置」里能看到 **AppID**，复制备用

> **要不要备案？不用。** 我们走的是「体验版」——只有你自己扫码能用，
> 不提交审核、不发布、不需要 ICP 备案。备案只在你想让别人也能搜到时才需要。
>
> 类目随便选一个贴边的即可（例如「教育 → 在线教育」或「工具 → 效率」），
> 它只影响模板申请，不影响使用。

---

## 第 2 步：装开发者工具，导入项目

1. 下载并安装 **微信开发者工具**（稳定版即可）
2. 打开 → 扫码登录 → 「导入项目」
3. 目录选到本仓库的 **`weapp/`** 文件夹（注意是 weapp，不是项目根目录）
4. AppID 填第 1 步拿到的那个

导入后先别急着编译，继续下一步。

---

## 第 3 步：开通云开发

1. 开发者工具顶部点 **「云开发」** 按钮 → 按提示开通
2. 开通后左上角会显示 **环境 ID**，形如 `cloud1-3gabcdefg123456`，复制备用
3. 在云开发控制台里手动建三个集合（数据库 → 集合管理 → 新建）：
   - `bindings`（绑定关系）
   - `todos`（待办）
   - `messages`（平台通知）
4. 三个集合的权限都设成 **「仅创建者可读写」**
   （云函数是管理员身份，不受这个限制；这个权限是拦住别人的小程序读你的数据）

> **关于费用**：云开发有 ¥0 的免费体验版（3000 资源点/月），个人自用绰绰有余。
> 但官方有一条规则要注意：**环境一旦随小程序「发布」，免费版会在上线后第 15 天到期**。
> 我们走体验版不发布，所以不受这条影响。真被停了就升 ¥19.9/月 的个人版。

---

## 第 4 步：申请订阅消息模板

1. 回 mp.weixin.qq.com → 左侧 **功能 → 订阅消息** → 「选用模板」
2. 在公共模板库里搜 **待办 / 日程 / 任务** 之类的字眼
3. 挑一个包含这几个关键词的模板：
   - **待办事项**（文本）
   - **截止时间**（时间）
   - **来源 / 备注**（文本）
4. 选用后，页面上会给出 **模板 ID** 和每个字段的英文名（如 `thing1`、`time2`、`thing3`）

> 字段名跟你选的模板有关，**代码里默认是 `thing1` / `time2` / `thing3`**。
> 如果你选的模板字段名不一样，第 5 步在云函数环境变量里改掉就行，不用动代码。

---

## 第 5 步：部署云函数

对 `cloudfunctions/` 下的 **三个函数**（`bind`、`ingest`、`remind`）各做一次：

1. 在开发者工具左侧文件树里右键该文件夹 → **上传并部署：云端安装依赖**
2. 部署完成后，去**云开发控制台 → 云函数 → 选中该函数 → 配置**，添加环境变量：

### `ingest` 的环境变量

| 变量名 | 值 |
| --- | --- |
| `INGEST_KEY` | 自己想一串足够长的随机字符（比如 32 位），电脑端要用同一个 |

### `remind` 的环境变量

| 变量名 | 值 |
| --- | --- |
| `TEMPLATE_ID` | 第 4 步拿到的模板 ID |
| `MP_STATE` | `trial`（体验版；以后正式发布改成 `formal`） |
| `ALWAYS_SEND` | 不用填。填 `true` 表示「每天必发」，哪怕一条待办都没有 |
| `FIELD_TITLE` / `FIELD_TIME` / `FIELD_SOURCE` | 只在字段名不是默认值时才需要填 |

`bind` 不需要环境变量。

### 配 HTTP 访问服务（让电脑能把数据推上来）

云开发控制台 → **HTTP 访问服务** → 添加路径：

| 路径 | 指向的云函数 |
| --- | --- |
| `/ingest` | `ingest` |

保存后会得到一个 **访问地址**（形如 `https://xxxx.service.tcloudbase.com/ingest`），
复制它，第 7 步电脑端要用。

---

## 第 6 步：填 config.js

打开 `weapp/miniprogram/config.js`，填两个值：

```js
ENV_ID: 'cloud1-3gabcdefg123456',        // 第 3 步拿到的环境 ID
TEMPLATE_IDS: ['模板ID'],                 // 第 4 步拿到的，可以填 1~3 个
```

> `TEMPLATE_IDS` 为什么可以填多个：用户点一次「允许」只能给你发一条消息的额度。
> 一次请求最多能带 3 个模板，填满 3 个就等于「点一次攒 3 条额度」。

填完在开发者工具里点「编译」，小程序应该就能打开了。

---

## 第 7 步：上传体验版

1. 开发者工具右上角点 **「上传」** → 填个版本号（如 `1.0.0`）
2. 上传成功后，回 mp.weixin.qq.com → **管理 → 版本管理**
3. 在「开发版本」里找到刚传的版本 → 点 **「选为体验版本」**
4. 页面会生成一个 **体验版二维码**，用你自己的微信扫码就能用了

> 如果提示「你不是体验成员」，在「成员管理 → 体验成员」里把自己的微信号加进去。

---

## 第 8 步：把电脑和小程序绑起来

1. 打开小程序的 **「我的」** 页面，会看到一串 **8 位绑定码**（比如 `K7M2XQ4P`），点一下就能复制
2. 在电脑上打开 `sync/push_config.json`，填三个值、把 `enabled` 改成 `true`：

```json
{
  "enabled": true,
  "baseUrl": "第 5 步拿到的 HTTP 访问地址（形如 https://xxx.service.tcloudbase.com/ingest）",
  "ingestKey": "第 5 步给 ingest 配的那个 INGEST_KEY",
  "bindCode": "小程序「我的」页面上的 8 位绑定码"
}
```

> 这个文件里有密钥，**不要上传到 GitHub 或发给别人**。项目里的 `.gitignore` 已经把它排除了。

3. 先空跑一次确认配置对不对（不会真的发送）：

```
.venv\Scripts\python.exe sync\push_to_cloud.py --dry-run
```

   看到「准备推送 N 条待办」就说明配置读到了。去掉 `--dry-run` 再跑一次就是真推。

4. 双击 `一键同步数据.bat` 跑一次 → 待办就会出现在小程序里
   （之后每次自动同步都会顺带推送，不需要你再管）
5. 在小程序首页点 **「补充提醒额度」** → 微信弹出订阅授权 → 点「允许」
   （弹窗里记得勾上 **「总是保持以上选择」**，以后就不用手动点了）

之后就等着收微信服务通知就行。云函数 `remind` **每天 20:30** 跑一次，
给你发一条速报：今天新增了几条待办、有什么接下来要到期、还有多少积压。

**当天真的没事就不发** —— 一条待办都没新增、也没有快到期的，就不占你一条订阅额度。

> 为什么是「每天一条速报」而不是「截止前 N 小时提醒」：实测抓到的待办里
> 绝大多数**根本没有写截止时间**（老师发通知常说「习题1」「第一次作业提交」，
> 就是不写几号交）。只做到期提醒的话，这些待办永远不会提醒你。

---

## 出现问题时怎么排查

推送这条链路上任何一环断了，**都不会影响电脑上的工作台**（它照常有数据），
只是手机上收不到。按这个顺序查最快：

| 现象 | 先看哪里 |
| --- | --- |
| 小程序里一条待办都没有 | 电脑上跑 `push_to_cloud.py --dry-run`，看能不能读到待办 |
| 提示 `BAD_KEY` | 两边密钥不一致：`push_config.json` 的 `ingestKey` ≠ 云函数 `ingest` 的 `INGEST_KEY` |
| 提示 `NO_BINDING` | 绑定码抄错了，或者在小程序里点过「换一个」之后没更新电脑上的值 |
| 待办有、但收不到通知 | 小程序「我的」页面看额度是不是 0；再看 `remind` 云函数日志 |
| 电脑上也没数据了 | 那是同步本身的问题，跟这个小程序无关，看工作台里的橙色登录态告警 |

## 常见问题

**Q：一天能收到几条提醒？**
固定**每天最多一条**（20:30 那条速报）。当天没事就不发。
够不够用取决于你多久打开一次小程序 —— 每次打开会自动补 3 条额度。

**Q：模板字段显示的名字跟内容对不上，比如字段叫「任务名称」却显示「新增 2 条 · 1 条将到期」？**
正常。模板里的字段名只是微信那边的**标签**，实际显示的文字完全由代码决定。
选模板时只要保证有「一行短文本 + 一个时间 + 一行短文本」这三个字段就行。

**Q：电脑关机了还会提醒吗？**
会。提醒是**云端定时器**发的，不依赖你的电脑。
但数据需要电脑同步过才会有——所以电脑至少每天要开机跑一次自动同步。

**Q：为什么收不到通知？**
按顺序查：① 小程序「我的」页面额度是不是 0；② 云函数 `remind` 的
`MP_STATE` 是不是 `trial`（体验版填 formal 会发不出去）；
③ 云开发控制台 → 云函数 → `remind` → 日志，看有没有报错。

**Q：能改成提前 3 天提醒吗？**
能。改云函数 `remind` 的环境变量 `LEAD_HOURS`，比如 `72`。
