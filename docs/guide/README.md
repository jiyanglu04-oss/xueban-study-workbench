# 图文教程与版本说明

本目录包含 26 页 PDF、文字教程、18 张原始电脑端截图与 12 张操作指引图。所有截图来自独立演示副本，不是作者个人账号数据，也不是 AI 重绘。

教程基于 v1.3；本仓库为 v1.3.1，已有功能的位置保持一致。PDF 第 13 节所述快捷脚本的 runtime 环境路径问题，在 v1.3.1 已增加兼容和回归测试。其余关于“用户核对日期/课表”“自己登录平台”“定时同步与提醒需分别开启”的限制仍然适用。

教程中的学校、老师、通知、网课进度、考试日期均为虚构示例，不要照抄到自己的课表。课表识别是生成草稿，必须校对。

优先阅读仓库 README.md；下载软件请到 Releases。本目录的 PDF 与图片本身不能运行工作台。
